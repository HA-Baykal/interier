## Errors & Solutions
_Problems encountered and how they were resolved. What approaches failed?_

- Next 14 build failed: `Route "src/app/api/auth/vk/route.ts" does not match the required types of a Next.js Route. "verifyVkSignedToken" is not a valid Route export field.` → route files may only export handlers/config; moved the helper (+`VkVerify`) into `src/lib/vk-miniapp.ts` and imported it.
- `GET /api/gallery` and `GET /api/marketplaces` were built as **○ (static)** → a production build froze them (published design never appeared in the gallery; 42-item run showed 6 stale seeded entries). Fix: `export const runtime = "nodejs"; export const dynamic = "force-dynamic";` + `await ensureBootSafe()` in both. Symptom to remember: a mutable GET route without `dynamic` looks fine in dev and silently stale in prod.
- Python patch inserted new i18n keys **after** `};` of the `ru` dict (anchor `"\nconst en: Dict = {"`) → `TS1005: ';' expected`. Fix: cut the block and re-insert before the dict's closing brace (`s.rindex("};", 0, en_idx)`); always re-run the ru/en key-set diff afterwards.
- `tg()?.HapticFeedback?.notification("x")` → TS2722 because the inner method is optional: must be `.notification?.("x")`.
- Instruction parser over-matched: «меня устраивает цвет и стиль штор, замени только шторы» also targeted «Растения и кашпо» — `matchCategories` used `norm.includes(stem)` and the plants stem `цвет` matched the word «цвет». Fixes: (a) `stemHit()` word-start anchored regex (also kills `тв` inside «декоративный»), (b) plants stems → `цветок/цветы/цветочн/растен/кашпо/горш/plant/potted`, (c) parse per **clause** (split on `,;:!?` too), `LIKE_MARKERS` («устраивает/нравится») protect + record `liked`, and `только X` → `exclusiveSet` replaces the whole target set; `liked` adds a "preserve these qualities" prompt line. Result: 1 target, 1 changed item.
- `pkill -f "next start"` / `pgrep -f "next-server"` killed the agent's own bash (pattern matches its own command line) — use `fuser -k 3000/tcp`.
- Earlier session: `fetch_page https://dev.max.ru/docs-api/tag/Messages` 404 (use `/docs-api/methods/…`); `dev.vk.com` returns a maintenance page (VK signature verification made toggleable: `vk_verify_signature=0`, VK Mini App login fails closed → `/api/auth/link`); heredocs need `mkdir -p` first; index-based python slicing on common JSX strings corrupts files (use `write_file` for whole-file rewrites of `Studio.tsx`).
